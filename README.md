# Flores amarillas

Una experiencia móvil en Angular donde un gatito pixelado entrega una flor amarilla y revela una dedicatoria de amistad elegida al azar. La tarjeta musical abre «Flores Amarillas» de Floricienta en Spotify.

## Ejecutar

```bash
pnpm install
pnpm start
```

Cada visita muestra una dedicatoria al azar. «Volver a ver el regalo» elige otra frase.

## Publicación

Cada cambio en `main` se publica en [GitHub Pages](https://alli293.github.io/flores-amarillas/).
